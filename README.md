# Flight Delay, Cancellation and Airline Performance Analysis using Python

# ✈️ Flight Delay, Cancellation & Airline Performance Analytics

## 📌 Project Description

A data analytics project focused on analyzing flight operations, airline performance, flight delays, and cancellations using Python. The analysis uses Python for data cleaning, transformation, exploratory data analysis, statistical analysis, and data visualization.

The project aims to identify flight delay patterns, analyze airline performance, understand cancellation trends, and generate meaningful insights from real-world airline operational data.

## 📊 Dataset

**Dataset:** T_ONTIME_REPORTING.csv

**Dataset Size:** 547,271 rows × 22 columns

**Time Period:** January 1, 2024 – January 31, 2024

**Format:** CSV

**Region:** United States

**Source:** U.S. Department of Transportation – Bureau of Transportation Statistics (BTS)

[View Dataset Source](https://transtats.bts.gov/DL_SelectFields.aspx?QO_fu146_anzr=&gnoyr_VQ=FGJ)

### Dataset Features

The dataset contains information related to:

* Flight dates
* Operating carriers
* Origin airports
* Destination airports
* Departure delays
* Arrival delays
* Cancellation information
* Air time
* Flight distance
* Flight operation details
* Day of week and month information
* Quarter and year details
